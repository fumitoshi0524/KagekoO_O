# Kageko CLI

Kageko is a terminal coding agent. Run it from the repository you want it to work in.

Requires Node.js 24 or later.

```sh
npm install --global @kageko/app
kageko setup
kageko
```

For permissions, configuration, development, and source installation, see the
[project README](https://github.com/fumitoshi0524/KagekoO_O/tree/agent-0.x#readme). Read the
[security boundaries](https://github.com/fumitoshi0524/KagekoO_O/blob/agent-0.x/docs/security-boundaries.md)
before enabling shell tools, unattended mode, or project extensions.
